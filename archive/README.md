# Archive

This folder contains the nine first versions of the demo websites. The three simple demos in the repository root replace them. The workflow does not publish these versions.

| Folder | Brand and concept |
|---|---|
| `aureline-atelier` | Aureline: editorial interior design studio |
| `the-transformation` | Aureline: portfolio with a before-and-after slider |
| `colour-studio` | Aureline: colour discovery tool |
| `truecoat-trusted` | TrueCoat (affordable and reliable): trust and enquiry form |
| `truecoat-transformations` | TrueCoat (affordable and reliable): portfolio with a slider |
| `truecoat-paint-plan` | TrueCoat (affordable and reliable): colour planner |
| `truecoat-complete` | TrueCoat (all budgets): flexible painting options |
| `truecoat-homes` | TrueCoat (all budgets): portfolio with a slider |
| `truecoat-your-colours` | TrueCoat (all budgets): planner with a requirements summary |

To run a version, open its folder, run `npm install`, and then run `npm run dev`.
